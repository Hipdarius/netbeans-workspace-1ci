# Z1 · Board Game Club Desk

**SCIPR 1CI mock exam 1** · 180 minutes · 60 points

| Material | Details |
| --- | --- |
| [Part I · Modelling](docs/Z1_BoardGameClubDesk_Modelling.pdf) | 11 points. Allow up to 35 minutes. Draw your UML on paper. |
| [Part II · Implementation](docs/Z1_BoardGameClubDesk_Implementation.pdf) | 49 points. Includes the definitive UML, Java tasks and written questions. |
| [Download the NetBeans starter](docs/Z1_BoardGameClubDesk_Starter.zip?raw=1) | Includes the NetBeans project, Swing form, Gson and sample files. |

This mock covers a player roster, a board with moveable markers and German notes tools. The tasks practise linked lists, JSON, collections, Swing painting, search and recursion.

## Open and run

1. Use **JDK 11 or newer** for the project. Open this folder from a repository checkout, or extract the starter ZIP and open the inner `Z1_BoardGameClubDesk` folder using **File → Open Project**.
2. Before timing, press **F6** and confirm that **Board Game Club Desk** opens. Close the window. Keep Part II and the source tabs closed until you finish Part I.
3. In Part II, use **Source Packages → boardclub → MainFrame → Design** to inspect the supplied form. Complete the named TODOs in **Source** and answer the written questions in the paper.

## Sample files

- `example-players.json` supplies test roster data. To use **Load JSON**, copy it to `players.json` in the project folder. **Save JSON** writes `players.json`.
- `words-de.txt` and `dictionary-de-fr.txt` supply the German word list and translations.
- Gson is bundled in `lib/` with [its license](lib/LICENSE-Gson.txt). Keep the supplied data files beside `build.xml`.

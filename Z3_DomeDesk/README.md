# DomeDesk

**1CI SCIPR · Devoir en classe · 180 minutes · 60 points**

A planetarium has one dome. Use a linked list to schedule recorded and live shows, account for setup time, and count bookings per school group.

| Material | When to use it |
| --- | --- |
| [Part A · Printable modelling paper](docs/Mock_Exam_2_Modelling.pdf) | Start here. Draw your UML on paper and hand it in within 35 minutes. **15 points.** |
| [Part B · Printable implementation paper](docs/Mock_Exam_2_Implementation.pdf) | After Part A. Use the supplied UML to complete 13 programming questions. **45 points.** |
| [Download the NetBeans starter ZIP](docs/Mock_Exam_2_NetBeans_Starter.zip?raw=1) | Extract the archive and open the inner `DomeDesk` project, or open this repository folder directly in NetBeans. |
| [Setup, TODO locations and exam checklist](docs/Mock_Exam_2_README.md) | Find the marked methods, both sample files and hand-in checks. |

Use **Run Project (F6)** to launch the starter. Open `MainFrame.java` and choose **Design** to inspect the Swing form. The project targets Java 11 and uses the standard Java libraries.
